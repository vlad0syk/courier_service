# 🚀 Courier Service System

## 🌟 Project Overview
This project is an **automated management system for a courier service**, developed as part of the academic course "Software Development Technology and Process."

The system is designed for the efficient registration of orders, delivery status tracking, and managing the database of couriers, ensuring a smooth and continuous workflow.

---

## ✨ Key Features
* **Order Registration and Management:** Allows adding new orders with complete details regarding sender, recipient, and delivery location.
* **Status Tracking:** Provides the capability to update delivery status in real-time (In Warehouse, In Transit, Delivered).
* **Courier Management:** A user-friendly database for accounting for employee data and their assigned tasks.
* **Modularity:** Clear code structure for easy maintenance and future scaling.

## 🛠️ Technologies and Requirements
The following are required for the system to operate:
* **Programming Language:** C++
* **Version Control System:** Git
